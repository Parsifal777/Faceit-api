Backend-приложение для управления киберспортивной платформой с автоматическим подсчётом статистики команд и игроков.
Faceit Admin Panel — это бэкенд-система для администрирования киберспортивных команд и игроков. Приложение позволяет:

✅ Управлять командами (CRUD)
✅ Управлять игроками (CRUD)
✅ Фиксировать результаты матчей с валидацией по правилам CS2 (MR12)
✅ Автоматически подсчитывать статистику:

Количество матчей и побед
Процент побед (Win Rate)
K/D (убийства/смерти)
K/R (убийства/раунды)

✅ Хранить данные в PostgreSQL и Redis

🔥 Особенности
Оптимизация запросов — решена проблема N+1 через JOIN FETCH и @EntityGraph
Двойное хранилище — PostgreSQL для данных, Redis для быстрых счётчиков
Атомарные операции — INCR в Redis для конкурентно-безопасных счётчиков
Логирование через АОП — @Loggable и @PerformanceLog аннотации
Валидация на всех уровнях — DTO, Service, БД
Spotlight UI — интерактивные эффекты в административной панели

Требования
Java 21+
PostgreSQL 15+
Redis 7+
Maven 3.8+
